Добираю до ~2.2B, но честно объясню компромисс по квотам — тут есть арифметика, которую не обойти.

**Что сейчас в миксе (после добавлений):**

| домен | квота | факт | комментарий |
|---|---:|---:|---|
| энциклопедический | 9 % | ~35 % | перебор: весь русский bulk — это Википедия |
| математика | 25 % | ~20 % | близко |
| литература | 11 % | ~15 % | Викитека добрала |
| наука | 14 % | ~12 % | физика добавлена |
| код | 15 % | ~8 % | только англ. |
| ML | 12 % | ~4 % | не хватает источников |
| логика | 10 % | ~3 % | только mathlib + вики |
| CS/инженерия | 3 % | ~2.5 % | сейчас качаю RFC |
| юмор | 1 % | ~0.2 % | мало PD-источников |

**Почему энциклопедический перебирает.** Все крупные русские источники с нормальной лицензией — это Википедия и Викитека. Чтобы дать русскому ≥30 % токенов (твоё требование), приходится брать их объёмом; другого русского текста такого качества и масштаба просто нет под CC. Если урезать Википедию до квоты 9 %, русских токенов останется ~24 %, и гейт не пройдёт.

**Почему не добиваю ML и логику до 12 % и 10 %.** Чтобы закрыть их на 8 ГБ микса, нужно ещё ~1.3 ГБ узких данных, то есть ~2.6B токенов и ~110k шагов. При квоте Kaggle 30 GPU-часов в неделю это уже две недели вместо одной. Ты просил «где-то до 2.2» — я держу 2.2–2.3B и не раздуваю.

**Что добавляю прямо сейчас:** RFC (IETF) — первичные спецификации интернета, домен CS/инженерия, ~100 МБ, лицензия позволяет распространение. Это самый качественный источник под недобор CS, лучше вики-категорий.

**Итог:** ~2.25B токенов, русский ~35 %, гейт ≥2B и ≥30 % проходит. Недоборы ML и логики останутся и будут честно записаны в отчёт — их логичнее добирать отдельным проходом после Q10 (arXiv full text для ML, Isabelle/AFP и Open Logic для логики), иначе претрен растянется на две недели.
