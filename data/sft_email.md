# SFT-датасет собран: 471 млн токенов, 2.47 млн примеров

Отвечаю на вопрос «отправь состояние SFT-датасета или ты пока не собирал»: до
сегодня был только Dolly-15k на 15 тысяч примеров — то есть практически ничего.
Сейчас собрано нормальное: **470 860 276 токенов** (461.4 млн train, 9.4 млн
val), 2 468 192 примера, математика с перевесом.

## Что именно лежит

| | |
|---|---|
| файлы | `data/sft/train.bpe.bin`, `val.bpe.bin` (uint16, EOT после примера) |
| индекс | `data/sft/sft_index.npy` — `(start, prompt_tokens, total_tokens, file)`, чтобы маскировать лосс на промпте без перетокенизации |
| шаблон | `<|system|>…<|eot|><|user|>…<|eot|><|assistant|>…<|eot|>` |

| отчёт с числами | `data/report_sft.md`, решения и дырки — `docs/sft.md` |

## Доля языков — как в претрейне

- по **байтам**: 59.3 % английский / 40.7 % русский — ровно контракт 60/40;
- по токенам: 68.1 % / 31.9 %, потому что русский стоит ~5 байт на токен против
  ~2.4 у английского (и математика с цифрами особенно «дорогая» по токенам).

То же самое было в претрейне (39.3 % байт → 33 % токенов), так что пропорция
сохранена именно в тех единицах, в которых вы её задавали.

## Источники

Математика EN: OpenMathInstruct-2 (срез 1M), MetaMathQA, Orca-Math,
MathInstruct, GSM8K, MATH. Математика RU: переведённые Orca-Math и MathInstruct,
русские math-диалоги, ru-alpaca-math. Плюс **1.4 млн синтетических
арифметических задач** (13 семейств × 2 языка): примеры, выкладка и ответ
считаются питоном, поэтому ответы точные, лицензия CC0.

Вопросы-ответы EN: OpenOrca, OpenHermes-2.5, HotpotQA. RU: saiga_scored (только
оценка ≥ 6), russian_instructions_2. Форумы EN: дамп Stack Exchange (лучший
ответ на ветку), ELI5, Reddit top-Q&A. Форумы RU: два зеркала otvet.mail.ru —
**390 818 и 418 394 пары**, они и дали основную массу «вопросных» данных.

Код: 132 476 пар вопрос→сниппет (RU). Identity: 1600 пар из наших CC0-абзацев.

## Что отфильтровано (и почему это важно)

Фильтры режут по длине, по отказам («Извините, я не могу», «As an AI»),
по скрипту (кириллица ≥ 25 % для RU), по петлям (разнообразие 5-грамм < 70 %) и
по точным дублям. Примеры потерь: hotpotqa отдал 16 655 из 90 447 (короткие
ответы), saiga 25 397 из 41 609 (оценка ниже 6), mailru_old 418 394 из 714 000.
Самый частый отказ по корпусу — `answer_length`; для mail.ru порог опущен до 32
символов, потому что там ответы короткие по природе, и с общим порогом 120
отваливалось 98 % данных.

## Почему я не буду гонять все 471 млн в SFT

Один шаг — 16 384 токена, значит 471 млн токенов это ~28 700 шагов, то есть
примерно 20 GPU-часов на 10M модели ради одной эпохи SFT. Это больше, чем даёт
пользы: при 10M параметрах SFT на десятках миллионов токенов уже начинает
запоминать, а не учиться. Поэтому в конфиге `S10` стоит 4 000 шагов
(65.5 млн токенов, 13 % запаса) — а остальное лежит как резерв, из которого
можно собрать другой микс без новых скачиваний.
