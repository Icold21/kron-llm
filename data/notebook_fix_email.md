# Чекпоинта нет в репозитории — это нормально, ноутбук это теперь переживает

`max(REPO.glob("**/*.pt"))` упал не из-за ноутбука и не из-за установки: в
свежем клоне просто нет ни одного `.pt`. Чекпоинт — артефакт прогона, в git он
не лежит (114 МБ вместе с состоянием оптимизатора), в репозитории из весов есть
только `artifacts/q8g_int8.pt` и `artifacts/q2_int8.pt` — это TinyStories-модель
на 2.85M, не Q10.

Плюс вторая мина: `data/bilingual/tokenizer.json` тоже в `.gitignore`, так что
даже с весами ноутбук не смог бы токенизировать текст.

## Что я поправил в ноутбуке

- репозиторий ищется относительно рабочей директории (корень или `notebooks/`),
  а не по моему абсолютному пути;
- чекпоинт ищется в `data/kaggle_out/q10/last.pt`, `data/kaggle_ckpt/last.pt` и
  `runs/*/last.pt`;
- если ни одного нет — ячейка сама тянет `icold21/kron-q10-ckpt` через
  `kaggle datasets download ... --unzip`;
- если и это не вышло — печатает три варианта вместо трейсбека;
- токенизатор берётся из `data/bilingual/tokenizer.json`, а в свежем клоне — из
  `artifacts/q10_tokenizer.json` (643 КБ, положил в репозиторий).

Оба сценария проверил: с чекпоинтом грузится и печатает шаг 11 723, 9 938 886
параметров; без чекпоинта и без `kaggle` в PATH выводит ровно этот список
вариантов. Запускать надо из корня клона (или из `notebooks/`).

## Как получить веса на ноутбук

1. **С Kaggle** (проще всего, если там уже логинен):
   ```
   pip install kaggle
   ```
   положить `kaggle.json` от аккаунта icold21 в `%USERPROFILE%\.kaggle\`, потом
   ```
   kaggle datasets download icold21/kron-q10-ckpt -p data/kaggle_ckpt --unzip
   ```
   Ноутбук сделает это и сам, если файла нет.
2. **С машины, где идёт обучение**: скопировать
   `C:\Users\Icold\Desktop\kron_llm\data\kaggle_out\q10\last.pt` (114 МБ) —
   по локальной сети или флешкой. Положить в `data/kaggle_ckpt/last.pt`.
3. **Проверить только пайплайн**: взять `artifacts/q8g_int8.pt` — но это другая
   модель (2.85M, TinyStories, английский), для проверки что код живой, а не для
   осмысленной генерации.

Важно понимать, что 114 МБ — это `last.pt` с состоянием AdamW: для инференса
хватило бы 40 МБ весов. Если понадобится третьему человеку, сделаю отдельный
экспорт «только веса» и опубликую его как маленький датасет; для себя
скачивать и так нормально.
